# ADLANE AI

واجهة عربية باتجاه RTL مع محادثة Gemini عبر Netlify Function من جهة الخادم.

## النشر على Netlify

1. من Netlify، أنشئ موقعاً جديداً باستيراد مستودع GitHub: adelkaila16-dot/ADLANE-AI.
2. استخدم إعدادات البناء الموجودة في netlify.toml: مجلد الموقع هو جذر المستودع، ومجلد الوظائف هو netlify/functions.
3. في إعدادات الموقع على Netlify، أضف متغير البيئة GEMINI_API_KEY وضع فيه مفتاح Google Gemini. أضفه في سياق النشر الذي ستستخدمه، ثم احفظه كقيمة سرية إذا ظهر هذا الخيار.
4. انشر الموقع أو أعد نشره بعد إضافة المتغير. لا تضع المفتاح في ملفات HTML أو JavaScript ولا تحفظه في GitHub.
5. افتح رابط Netlify، انتقل إلى المحادثة، وأرسل رسالة بالعربية للتأكد من ظهور الرد. عند الفشل، راجع سجلات وظيفة chat في لوحة Netlify.

## ملاحظات التشغيل والأمان

- يستدعي المتصفح المسار نفسه على الموقع: /.netlify/functions/chat. يقوم الخادم فقط بقراءة GEMINI_API_KEY وإرساله إلى Google في ترويسة الطلب؛ المفتاح غير موجود في الواجهة الأمامية.
- لا تسمح الوظيفة بطلبات المتصفح عبر نطاقات خارجية، وتقبل POST فقط.
- GitHub Pages وJekyll يستطيعان نشر ملفات الموقع الثابتة، لكنهما لا يشغّلان Netlify Functions. يجب استضافة الموقع على Netlify حتى تعمل المحادثة.
- مفتاح Gemini غير مضمّن في هذا المستودع. أضفه إلى إعدادات Netlify قبل اختبار اتصال حقيقي.
